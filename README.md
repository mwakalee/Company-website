# Company Website (Spring Boot + TypeScript)

Modern IT company website starter with:
- **Spring Boot backend API** for profile content and contact form endpoint.
- **React + TypeScript frontend** with multiple page views (Home, Services, Work, About, Contact), responsive design, interactive service cards, FAQ accordion, and a chat assistant widget.
- **Docker support** for backend and frontend with a single `docker compose up --build` command.

## Run backend locally

```bash
mvn spring-boot:run
